Tugas Proyek Pengembangan Aplikasi Web

Portal Rekayasa Sistem Chatbot Fiqih Kontemporer

Platform integrasi sistem tanya jawab hukum Islam berbasis Retrieval-Augmented Generation (RAG). Mengembangkan sistem dari penelitian terdahulu dengan arsitektur terpisah (FastAPI) dan mitigasi ketergantungan API via Local SLM (VRAM 4 GB).

Modul & Fitur Pengembangan

Empat komponen kunci yang dirancang untuk mengatasi limitasi penelitian terdahulu:

01

RAG Fiqih Al-Qardhawi

Mesin penelusuran semantik berbasis FAISS terhadap 9 buku rujukan fatwa fiqih kontemporer.

02

FastAPI Backend Engine

Migrasi dari Streamlit ke REST API asinkron untuk menjamin skalabilitas ratusan pengguna simultan.

03

Hybrid Failover Router

Beralih otomatis antara Google Gemini 2.0 Flash (Cloud) dan Qwen 2.5 3B (Lokal) saat offline.

04

Hardware Ready (VRAM 4GB)

Optimasi kuantisasi 4-bit (GGUF/Q4) agar sistem lokal dapat dijalankan pada laptop standar tim.

Fokus Penyelesaian Masalah Tim

1. Skalabilitas Antarmuka (Streamlit → FastAPI + Caching)

Menghilangkan kendala script rerun bawaan Streamlit dengan memisahkan antarmuka pengguna ke web statis dan menambahkan Redis semantic cache untuk memproses kueri umum di bawah 50 ms.

2. Vendor Lock-in (Cloud Gemini → Small Language Model Lokal)

Menghapus risiko ketergantungan mutlak pada Google AI API dengan menyediakan model cadangan lokal yang hemat VRAM (Qwen 2.5 3B atau Gemma E2B) menggunakan server inferensi Ollama/vLLM.
