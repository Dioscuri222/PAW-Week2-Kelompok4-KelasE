1. Fokus Penelitian (Membahas Apa?)

Masalah yang Diangkat

Akses terhadap rujukan fatwa fiqih kontemporer sering kali terkendala tebalnya literatur kitab, keterbatasan waktu membaca, dan kompleksitas bahasa hukum Islam bagi masyarakat awam maupun mahasiswa. Sementara itu, problematika modern menuntut fatwa praktis yang kontekstual.

Solusi yang Dibangun: Chatbot RAG Fiqih

Penelitian ini mengembangkan Question Answering System (QAS) berbasis web menggunakan arsitektur Retrieval-Augmented Generation (RAG).

Alur Kerja Sistem:

1. Korpus Data: Mengonversi 9 buku fiqih kontemporer karya Syekh Yusuf Al-Qardhawi ke format PDF.
2. Vektorisasi & Retrieval: Teks dipecah (chunking), dikonversi ke vektor numerik via model embedding-001 Google, lalu diindeks ke dalam basis data vektor FAISS untuk similarity search.
3. Generasi Respon: Kueri pengguna dicocokkan untuk mengambil 3 referensi paling relevan, lalu dirangkum secara kontekstual oleh model Gemini-2.0-flash melalui orkestrasi LangChain.
4. Antarmuka: Dibangun berbasis web menggunakan framework Streamlit.

2. Kekuatan & Keunggulan Penelitian

Validasi Ganda (Ahli & Evaluator Otomatis)

Penelitian menggunakan pendekatan pengujian berlapis:

• User Acceptance Test (UAT): Melibatkan 7 responden ahli fiqih (3 ustadz dan 4 dosen) dengan tingkat kepuasan mencapai 89,00% (kategori "Sangat Setuju").
• LangChain Scoring Evaluator: Pengujian otomatis kesesuaian jawaban dengan teks rujukan menghasilkan skor rata-rata 95,00%.

Penggunaan Model Generatif Mutakhir

Penerapan gemini-2.0-flash memberikan waktu inferensi respons yang cepat (low latency) serta penalaran konteks semantik bahasa alami yang lebih baik untuk bahasa Indonesia dibandingkan LLM generasi sebelumnya.

Minimasi Halusinasi melalui Grounding Referensi

Jawaban tidak digenerasi secara bebas dari parameter umum LLM, melainkan dikunci (*grounded*) pada potongan dokumen hasil pencarian semantik sembilan buku rujukan serta menyertakan kutipan sumber kepada pengguna.

3. Kelemahan & Keterbatasan Metodologis

Bias Sumber Tunggal (Single-Scholar Limitation)

Basis pengetahuan hukum Islam hanya bersumber dari satu figur ulama, yakni Syekh Yusuf Al-Qardhawi. Sistem belum mengakomodasi komparasi fatwa lintas 4 madzhab besar (Hanafi, Maliki, Syafi'i, Hanbali) maupun fatwa ormas/lembaga lokal di Indonesia (MUI, Nahdlatul Ulama, Muhammadiyah).

Ukuran Sampel Uji Sangat Terbatas (Small Sample Size)

Validasi hanya menguji 10 butir pertanyaan dan 7 responden. Secara metodologis, jumlah ini belum mencukupi untuk menguji keandalan sistem terhadap pertanyaan jebakan, kasus hukum yang ambigu (*edge-cases*), atau pertanyaan yang mengandung distorsi istilah syariah.

Skalabilitas Antarmuka Web Rendah

Framework Streamlit sangat cocok untuk demonstrasi dan purwarupa cepat, namun memiliki kendala konkurensi bawaan jika diakses serentak oleh ribuan pengguna secara bersamaan.

Ketergantungan Penuh pada Cloud API Pihak Ketiga

Keterikatan (*vendor lock-in*) pada ekosistem Google AI API mengharuskan koneksi internet aktif dan biaya pemanggilan API berkelanjutan tanpa adanya opsi arsitektur *fallback* model luring (*open-source/on-premise*).

Peringatan Metodologis & Batasan Fiqih

Fatwa hukum Islam menyangkut ranah keyakinan dan peribadatan personal. Meskipun chatbot berbasis RAG menghasilkan skor kepuasan 89% dan evaluasi LangChain 95%, hasil generatif AI tetap tidak dapat menggantikan peran fatwa ulama secara mutlak.

Tingginya akurasi pada paper ini dipengaruhi oleh sempitnya cakupan dokumen (9 buku dari 1 ulama). Implementasi riil untuk publik memerlukan kurasi fatwa komparatif yang lebih luas serta validasi pakar berkelanjutan.
